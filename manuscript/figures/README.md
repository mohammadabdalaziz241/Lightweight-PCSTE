# Figures

## `fig_confusion_aggregated_fulls1_vs_k1.pdf`

Aggregated class-level confusion matrices for Full-S1 and K1 on CWRU, JNU, HIT
and MaFaulDa. Included via `figures/confusion_aggregated.tex`
(`\input` from `sections/04_results_discussion.tex`, label
`fig:confusion_aggregated`).

The asset is a vector PDF generated from the sealed publication TEST artifacts
by `scripts/generate_confusion_figure.py` in the publication repository. It is
copied here so the manuscript tree stays self-contained when archived or moved
to a journal/Overleaf project. Provenance, per-cell source hashes and the
verification log are in
`figures/confusion_matrices/confusion_matrix_aggregation_manifest.md` of the
publication repository; the underlying matrices are exported as CSV under
`figures/confusion_matrices/data/`.

Final architecture/overview artwork can be added here after co-author review
and target-journal selection.
